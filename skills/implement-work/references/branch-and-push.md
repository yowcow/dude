# Branch and Push

Shared wants with their end states for cutting a branch and pushing it.
How to bring each about is deliberately unwritten.

## Cut

The want is a branch under that name for this task.

The end state is that name existing locally and containing the expected fork source.

## Push

The want is the branch as a deliverable rather than local state.

The end state is `origin` holding the work branch under its own name and containing the local tip.
